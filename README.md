# Data-science-project-
 Sales Prediction Using Machine Learning
This project uses machine learning techniques to predict product sales based on historical data. Built using Python and key data science libraries, the model helps in understanding sales trends and forecasting future sales, which is valuable for inventory management, marketing strategies, and demand planning.
Features
Data preprocessing and exploratory data analysis (EDA)
Visual insights using Seaborn and Matplotlib
Model training using Linear Regression and other ML algorithms
Model evaluation using metrics like RMSE and R² score

Future sales prediction using the trained model

Tech Stack
Python 3.x
Pandas & NumPy
Matplotlib & Seaborn
Scikit-learn
Jupyter Notebook

Data Source
This project uses a preloaded dataset containing product sales data including features such as:
Item Weight
Item Visibility
Item Type
Outlet Size
Outlet Location Type
Item MRP
